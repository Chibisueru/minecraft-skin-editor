# Changelog

## v0.2.0-alpha (2026-11-23)

First public alpha.

- Paint on a rotatable, pannable, zoomable 3D player model
- Tools: Pencil, Eraser, Fill (limited to one face), Pick colour
- Base and overlay layers, with visibility per body part and per layer,
  and Clear overlay
- Classic and Slim arm models, detected automatically on open
- Opens 64×64 and legacy 64×32 skins (upgraded to 64×64)
- Tabs, up to 200 undo steps per tab, a confirmation before closing unsaved tabs
- Eight-slot palette, colour square, hue strip, and hex and RGB input
- Material 3 interface with light and dark themes in five accent colours,
  saved between runs
- Packages: Linux Flatpak and Windows `.exe`
